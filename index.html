    • Object-Oriented Programming (OOP)in Python is a programming paradigm that organizes code around **objects** and **classes**. It allows you to model real-world entities as objects, which have **attributes** (data) and **methods** (functions).

    OOP in Python is built around four main principles:

  • Encapsulation

  • Abstraction

  • Inheritance

  • Polymorphism

    • Class and Objects

  • Class: A blueprint or template for creating objects. It defines a set of attributes and methods that the created objects (instances) will have.
  • Object: An instance of a class. Each object can have its own unique attributes.

    • # Defining a class
    class Dog:
    # Constructor (__init__ method)
    def __init__(self, name, age):
    self.name = name # Instance variable
    self.age = age # Instance variable

    # Method to describe the dog
    def bark(self):
    print(f"{self.name} is barking!")

    # Creating an object (instance of the Dog class)
    my_dog = Dog("Buddy", 5)

    # Accessing object attributes
    print(my_dog.name) # Output: Buddy
    print(my_dog.age) # Output: 5

    # Calling the object method
    my_dog.bark() # Output: Buddy is barking!

    Encapsulation

  • Encapsulation is the concept of bundling the data (attributes) and methods that operate on the data within a single unit (class). It restricts direct access to some of the class’s components, which is known as **data hiding**.
  • In Python, you can achieve encapsulation using:
  • Public attributes: Accessible from outside the class.
  • Private attributes: Not directly accessible from outside the class (by convention, private attributes are prefixed with an underscore `_` or double underscore `__`).

    • class Car:
    def __init__(self, make, model):
    self.make = make # Public attribute
    self._model = model # Private attribute

    # Method to access private attribute
    def get_model(self):
    return self._model

    # Creating an object
    my_car = Car("Toyota", "Camry")

    # Accessing public attribute
    print(my_car.make) # Output: Toyota

    # Accessing private attribute directly is discouraged
    # print(my_car._model) # Not recommended (but still possible)

    # Accessing private attribute through a method
    print(my_car.get_model()) # Output: Camry

    Abstraction

  • Abstraction is the process of hiding the implementation details and showing only the necessary functionality to the user. In Python, abstraction can be achieved using abstract classes and methods.
  • Abstract Class: A class that cannot be instantiated and is meant to be subclassed.
  • Abstract Method: A method that is declared but contains no implementation. Subclasses must implement this method.

    • from abc import ABC, abstractmethod

    class Animal(ABC):
    @abstractmethod
    def sound(self):
    pass # Abstract method, to be implemented by subclass

    class Dog(Animal):
    def sound(self):
    return "Woof!"

    class Cat(Animal):
    def sound(self):
    return "Meow!"

    # Creating objects of Dog and Cat
    dog = Dog()
    cat = Cat()

    # Calling the implemented sound method
    print(dog.sound()) # Output: Woof!
    print(cat.sound()) # Output: Meow!

    Inheritance

  • Inheritance allows a class (child class) to inherit attributes and methods from another class (parent class). It promotes code reusability.
  • Single inheritance: A child class inherits from a single parent class.
  • Multiple inheritance: A child class inherits from multiple parent classes.

    • # Parent class
    class Animal:
    def __init__(self, name):
    self.name = name

    def speak(self):
    print(f"{self.name} makes a sound")

    # Child class inheriting from Animal
    class Dog(Animal):
    def speak(self): # Overriding the parent method
    print(f"{self.name} barks!")

    # Creating an object of Dog
    dog = Dog("Buddy")
    dog.speak() # Output: Buddy barks!

    # Parent classes
    class Animal:
    def __init__(self, name):
    self.name = name

    def eat(self):
    print(f"{self.name} is eating.")

    class Pet:
    def play(self):
    print(f"{self.name} is playing.")

    # Child class inheriting from both Animal and Pet
    class Dog(Animal, Pet):
    def __init__(self, name):
    Animal.__init__(self, name)
    Pet.__init__(self)

    # Creating an object of Dog
    dog = Dog("Buddy")
    dog.eat() # Output: Buddy is eating.
    dog.play() # Output: Buddy is playing.

    Polymorphism

  • Polymorphism allows objects of different classes to be treated as objects of a common superclass. The actual method to be called is determined at runtime. Polymorphism is often achieved through method overriding (in the case of inheritance) or through operator overloading.
  • Method Overriding: A method in the child class has the same name as the one in the parent class but provides a different implementation.
  • Operator Overloading: Overloading operators (like `+`, `-`, etc.) to behave differently based on the objects.

    • class Animal:
    def speak(self):
    print("Animal makes a sound")

    class Dog(Animal):
    def speak(self):
    print("Dog barks")

    class Cat(Animal):
    def speak(self):
    print("Cat meows")

    # Polymorphism in action
    animals = [Dog(), Cat()]
    for animal in animals:
    animal.speak()

    Output:

    Dog barks
    Cat meows

    #### Example of Operator Overloading:

    class Point:
    def __init__(self, x, y):
    self.x = x
    self.y = y

    # Overloading the + operator
    def __add__(self, other):
    return Point(self.x + other.x, self.y + other.y)

    def __str__(self):
    return f"({self.x}, {self.y})"

    # Creating Point objects
    p1 = Point(1, 2)
    p2 = Point(3, 4)

    # Adding two Point objects using overloaded + operator
    p3 = p1 + p2
    print(p3) # Output: (4, 6)
